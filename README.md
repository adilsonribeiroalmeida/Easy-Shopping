# 🛍️ Easy Shopping Via Mobile

Projeto desenvolvido como parte do meu aprendizado no **[Dev Club](https://www.devclub.com.br)**.

O **Easy Shopping Via Mobile** é uma landing page moderna e responsiva voltada para compras online via celular, com foco em uma experiência fluida e design atrativo.
